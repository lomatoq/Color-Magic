# Test scooter

Use **Workspace → Add test scooter**, or search **Add test scooter** with F3.
The collection appends to the current scene. It includes 23 surface zones,
glossy blue bodywork, light cyan seating, dark tires and metallic Accent hardware.
The metal follows Accent (Metallic 1.0, Roughness 0.26). Only the exhaust is Fixed
gold. The front is turned toward the studio camera.

The user supplied this Tripo scooter and requested its inclusion as the plugin's
test model. It is bundled as a Blender library; no network download is needed.
